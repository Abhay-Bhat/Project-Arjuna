Recovery Actions

Stamp & Restore sets _savedAt to now and writes the data back to IndexedDB. When you open the main app, the local timestamp will be newer than Firestore's, so the good data gets pushed back to the cloud automatically.

Manual Import (Fallback)

If the automatic restore doesn't work, download the backup JSON above, then open the main app → Settings → Import Data and select the downloaded file. The import sets a fresh _savedAt and triggers a Firestore push automatically.
